# 设计语言

面向长时间阅读的浅色纸张设计系统。三条总纲：**清晰**（信息层级分明）、**温和**（米白纸面降低刺眼反差）、**有触感**（纸纤维、墨色和轻阴影表达层级）。

> 本文是设计的最高标准。组件代码与本文冲突时，以本文为准。Tailwind 类名配方保持英文原样，方便直接复制使用。

---

## 排版

- 字体栈（`font-sans`）：Apple 平台用 SF Pro，中文回退到苹方（PingFang SC），其余回退到 Noto Sans SC / 微软雅黑。英文大标题用系统展示字体，不为纸张感强行套用中文衬线字。
- **字重**：所有标题与展示文字最多到 `font-semibold`，不用 `font-extrabold` / `font-bold`。正文强调用颜色，不用加粗。
- **标题层级**：
  - 首页大标题：`text-5xl md:text-6xl font-semibold tracking-[-0.015em]`
  - 全屏面板标题：`text-2xl font-semibold tracking-tight`
  - 弹窗标题：`text-xl font-semibold tracking-tight`
  - 区块小标题：`text-[17px] font-semibold tracking-tight text-zinc-100`
- **阅读区（字幕）**：英文是主、中文是辅，**任何状态下都恰好差一级**：
  - 英文：`text-base leading-relaxed tracking-normal`；激活 `text-zinc-50`，非激活 `text-zinc-400`。状态切换**只改颜色、绝不改字重**（避免文字回流）。
  - 中文：`text-[15px] leading-relaxed`；激活 `text-zinc-400`，非激活 `text-zinc-500`。
- **数字 / 时间**：用 `tabular-nums`、`text-[11px] font-medium`，不用等宽字体、不用方括号装饰。
- **中文排版禁忌**：不用 `italic`（苹方无斜体字形）、不对中文用 `uppercase` / `tracking-wider`。

## 颜色

- 中性色使用带暖色偏移的纸色与墨色：画布 `#EDE6D8`，表面 `#F5EFE3`，浮起纸面 `#FFFAF0`，主墨 `#29251F`，次墨 `#6F6659`。代码中现有 zinc 工具类由 `.paper-theme` 语义映射到这组颜色。
- **唯一的交互强调色**：蓝色（`blue-500`，品牌 token `#0A6FD6`）。链接、当前时间戳、画中画、进度、焦点环都用它。
- **保留色（仅表语义）**：
  - 紫色 —— **只**用于 AI 生词高亮（类名来自后端数据，不可挪用）
  - 翠绿 —— 成功 / 已处理 / 已订阅
  - 琥珀 —— 警告 / 听写模式 / 收藏星标
  - 红色 —— 危险操作
- **细边框**：使用偏棕的低对比发丝线，现有 `border-white/5` 与 `border-white/10` 由主题层分别映射为 20% 和 30% 墨色透明度。

## 材质

- 纸张材质沿用 `.glass-panel` / `.glass-card` 公共类名以保持组件 API 稳定，实际呈现为不透明暖白纸面、细边缘和双层轻阴影，不再使用 `backdrop-filter`。
- 顶栏 / 工具栏：画布色 92% 不透明表面 + 底部发丝线，内容滚动时仍能看清层级。
- 弹窗遮罩：32% 墨色遮罩，对话框使用浮起纸面、`rounded-2xl` 与明确的轻阴影。
- 首页背景只保留纸纤维噪点和轻微横线，不使用极光、粒子、流星或彩色渐变。

## 几何（圆角体系）

圆角按元素尺寸分级——同尺寸元素共用同一圆角：

| 档位 | 用途 |
|---|---|
| `rounded-md` | 分段控件滑块、行内单词高亮 |
| `rounded-lg` | 高度 ≤36px 的控件、图标按钮、缩略图、小标签 |
| `rounded-xl` | 卡片 / 列表行 / 按钮 |
| `rounded-2xl` | 浮层：弹窗、词典卡、提示、当前句高亮胶囊 |
| `rounded-3xl` | 页面级 bento 大面板 |
| `rounded-full` | 胶囊（首页搜索框、徽章、关闭按钮） |

Logo 方块：`rounded-[10px]`（40px 下的苹果图标曲率）。缩略图一律 `aspect-video rounded-lg`。

## 按钮（四种配方）

- **主按钮**：深墨色背景 + 暖白文字，代码仍用 `bg-zinc-100 text-zinc-900`，由 `.paper-theme` 反转映射；按压 `active:scale-[0.98]`，只过渡颜色、透明度与 transform。
- **次按钮**：次级纸面 + 墨色边缘 + 中等墨色文字，悬停时只加深纸面。
- **着色按钮**：`... bg-{色}-500/10 hover:bg-{色}-500/15 border border-{色}-500/20 text-{色}-400 ...`
- **幽灵文字**：`h-10 px-5 rounded-xl text-sm font-medium text-zinc-400 hover:text-zinc-100 hover:bg-white/5 transition-colors`
- **幽灵图标**：`p-1.5 rounded-lg text-zinc-500 hover:text-zinc-300 hover:bg-white/5 transition-colors`
- **关闭（X）**：弹窗 `p-2 rounded-full ...` + `w-5 h-5`；浮层/提示 `p-1.5 rounded-full` + `w-4 h-4`

## 通用配方

- **分段控件**（译文模式、生词水平、季选择共用）：容器是下沉纸色，选中态用深墨滑块与暖白文字（`motion.span` + `layoutId`，弹簧 `stiffness: 420, damping: 36`）。
- **列表行**（历史 / 更新 / 剧集 / 模型）：常态接近表面纸色，悬停加深 3% 到 5% 亮度差，用发丝线而不是浓重卡片边框。
- **徽章**：`text-[11px] font-medium px-2 py-0.5 rounded-full` + 着色。
- **空状态**：容器 `flex flex-col items-center justify-center py-16 text-center`；图标 `w-10 h-10 text-zinc-700 mb-3`；标题 `text-sm font-medium text-zinc-400`；提示 `text-xs text-zinc-600 mt-1`。
- **弹窗结构**：头 `px-6 py-5 border-b border-white/5`；体 `p-6`；脚 `px-6 py-4 border-t border-white/5`。

## 动效

- 微交互：`transition-colors duration-200`（位移/缩放用 `ease-apple` = `cubic-bezier(0.25,1,0.5,1)`）。**精确指定要动的属性**，少用 `transition-all`。
- 按压反馈：按钮 `active:scale-[0.98]`，卡片 `whileTap={{ scale: 0.98 }}`。**悬停绝不缩放列表行**——靠背景/边框变化表达。
- 标准弹簧：`{ type: 'spring', stiffness: 380, damping: 32 }`；分段滑块 `{ 420, 36 }`。
- 键盘焦点：全局统一 `:focus-visible` 蓝色环，不做每组件特例。
- 装饰性动效（极光、粒子、卡片倾斜）必须尊重 `prefers-reduced-motion`。

## 图标

只用 lucide-react，不手写内联 SVG。光学尺寸：紧凑工具栏 `w-3.5`，按钮内/折叠 `w-4`，区块标题 `w-5`。
