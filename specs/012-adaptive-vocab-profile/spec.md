# 规格：自动词汇画像

**状态：** 已实现 ｜ **对应代码：** `frontend/src/lib/vocabProfile.ts`、`frontend/src/components/VocabAssessment.tsx`、`frontend/src/components/SettingsModal.tsx`、`frontend/src/components/WordPopover.tsx`、`backend/translate.py`

---

## 目标

用短测评和真实学习反馈持续估计个人词汇水平，让生词高亮逐渐贴近用户，而不是只依赖一次主观选档。

## 用户故事

- 作为个人用户，我想用一次短测评获得初始画像，不必猜自己属于哪个档位。
- 作为学习者，我想明确标记“认识”或“学习”，让系统记住具体单词。
- 作为学习者，我希望复习表现能更新画像，让已经掌握的词减少高亮。
- 作为用户，我想随时重测、重置或切回手动六档。

## 功能需求

- **必须**：提供 12 题以内的自适应词义测评，题目随答题结果调整难度。
- **必须**：画像包含自动基线、可信度、已掌握词和学习中词，并只保存在本地。
- **必须**：词典卡支持“认识 / 学习”显式反馈；单纯点词不自动判定为不认识。
- **必须**：词汇收藏自动视为“学习中”；生词连续复习掌握后转为“已掌握”。
- **必须**：新视频处理时把画像摘要传给后端；已掌握词不高亮，学习中词优先高亮。
- **必须**：画像词表按长度限制后进入提示词，避免无界增加 token。
- **必须**：没有画像或数据损坏时回退到 Orbit，不影响翻译。
- **应当**：设置弹窗显示自动模式、可信度、重新测评、重置和手动六档兜底。

## 验收标准

- [x] 首次测评能完成 12 题并生成基线与可信度，刷新后仍保留。
- [x] 答对后题目整体变难，答错或“不认识”后题目整体变简单。
- [x] 词典卡反馈即时更新画像，认识与学习状态互斥。
- [x] 收藏生词进入学习中；连续掌握后进入已掌握。
- [x] 自动模式向翻译请求发送画像；手动模式继续发送六档水平。
- [x] DeepSeek 提示词明确区分已掌握词和学习中词，并限制词表大小。
- [x] 重置或损坏存档后安全回退，不影响字幕翻译。

## 边界与非目标

- 不声称测评等同标准化词汇量考试，结果用于调整生词高亮，不展示词汇量数字。
- 不上传完整学习记录，不新增账号、云同步或第三方测评服务。
- 不重算已缓存视频的高亮；画像只影响之后新处理或重新处理的视频。
