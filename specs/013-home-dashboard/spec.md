# 规格：个人主页工作台

**状态：** 已实现 ｜ **对应代码：** `frontend/src/components/InputScreen.tsx`、`frontend/src/components/SentencePacks.tsx`、`frontend/src/lib/progress.ts`、`backend/routes_videos.py`

---

## 目标

让个人用户在桌面浏览器中更快进入视频学习，并在一个紧凑工作台里查看最近记录、本地剧集和订阅更新，避免内容被限制在窄列中产生大面积留白。

## 用户故事

- 作为桌面端用户，我想充分利用宽屏，同时看到多个学习入口和动态。
- 作为个人用户，我想删除不再需要的最近学习记录，保持主页干净。
- 作为以视频学习为主的用户，我希望句子精背保留入口但不抢占首要位置。

## 功能需求

- **必须**：桌面宽屏使用多列布局并扩大内容最大宽度，移动端仍保持单列。
- **必须**：主页大面板使用较小且统一的圆角，列表行和按钮使用更小一级圆角。
- **必须**：最近学习作为主要区域，展示清晰的视频标题、频道、视频时长、进度和删除操作。
- **必须**：最近更新展示视频标题、频道和视频时长，便于用户判断学习投入。
- **必须**：删除前明确说明会移除本地学习缓存且无法恢复；确认后只删除所选文件，失败时保留原记录并提示原因。
- **必须**：后端删除接口拒绝路径穿越、保留数据文件和非学习历史 JSON。
- **应当**：句子精背移动到主内容之后或缩为次级紧凑入口。

## 验收标准

- [x] 1280px 及以上宽度下，主页主内容形成多列且左右无明显大块空白。
- [x] 375px 宽度下自动回到单列，无横向滚动和控件溢出。
- [x] 大面板、列表行和操作按钮的圆角层级清晰，页面不再以大圆角为主要视觉特征。
- [x] 删除一条最近学习记录时先出现确认，确认后该行消失且刷新后不再出现。
- [x] 最近学习与最近更新的缩略图显示 `m:ss` 或 `h:mm:ss` 格式的视频时长，未知时长不显示空徽标。
- [x] 伪造文件名、保留数据文件或非历史文件无法通过删除接口移除。
- [x] 句子精背仍可进入，但视觉权重低于最近学习、本地剧集和订阅更新。

## 边界与非目标

- 删除学习历史不会联动删除收藏、生词画像或订阅。
- 本次不新增批量删除、回收站或云端同步。
- 移动端继续采用适合触控的单列布局，不强制套用桌面多列。
